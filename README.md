# Pixel Colors 🎨

A cozy pixel-art color-by-number game made with **HTML, CSS, and vanilla JavaScript** — no React and no build tools.

## Run locally
1. Download and unzip the project.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.
3. Choose a picture, pick a palette color, and click matching numbered pixels.

## Features
- Responsive pastel three-panel layout
- Eight original pixel-grid pictures
- Color-by-number interaction and progress counter
- Fill all remaining pixels for a selected color
- Eraser, reset, hints, favorites, and page navigation
- Progress and favorites saved with browser local storage
- Keyboard shortcuts: `1`–`6` select colors

## Files
- `index.html` — page structure
- `style.css` — layout and visual styling
- `script.js` — pixel art definitions and game logic
